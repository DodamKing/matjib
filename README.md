# 🍚 matjib — AI 결정장애 치료기 (식당 편)

> **"더 이상 고르지 마세요. 걸어서 5분 거리 청정 맛집, 딱 3개만 처방해 드립니다."**

점심마다 "오늘 뭐 먹지?"로 10분씩 고민하는 당신을 위한 서비스.
정보를 *더* 보여주는 대신 **극단적으로 줄여서** 결정을 대신 내려줍니다.

## ✨ 컨셉

- **딱 3개만**: 리스트도, 무한 스크롤도 없습니다. 화면엔 카드 3장뿐. (Zero-Scroll)
- **밥집·카페·술집**: 지금 찾는 게 뭔지 한 번만 고르면 그 종류로만 처방. (기본 밥집)
- **도보 5분**: 실시간 위치 기준 걸어갈 수 있는 곳만. (5/10/15분)
- **셔플**: 마음에 안 들면? 새로운 3개를 다시 처방받으세요.
- **상황 태그**: 해장·든든하게·가볍게 등 태그를 톡톡 누르면 지금 상태에 맞게 좁혀줍니다.
- **앱 안에서 길찾기**: 외부로 튕기지 않고, 카드 → 앱 안 상세 시트에서 지도 미리보기·방향·거리·주소를
  먼저 보고(탭하면 지도 확대) 카카오맵/네이버지도 중 골라 나갑니다.
- **원클릭 진입**: 가입도 앱 설치도 없이, 링크 접속 후 위치 동의 한 번이면 끝.

## 🛠 기술 스택

- **Next.js (App Router) + TypeScript**
- **Tailwind CSS** — 모바일 우선 미니멀 UI
- **데이터**: 소상공인시장진흥공단 상가(상권)정보 공공데이터 API
- **상황 매칭**: LLM 없이 상황 태그 → 키워드 매칭 (결정론적)

## 🚧 진행 상황

초기 개발 중. **Phase 3 실데이터 연동 완료** — 이제 더미가 아니라 **소상공인 상권정보 공공데이터 실데이터**로
내 위치 반경의 음식점을 조회해 상황 태그로 좁히고 3장을 처방합니다. 길찾기도 외부로 튕기지 않고
**앱 안 상세 시트(지도 미리보기 포함)**로 감쌌습니다. 다음은 Vercel 배포.

- ✅ 위치 동의 → 도보 5/10/15분 필터 → 카드 3장 → 셔플
- ✅ 검색 모드(밥집/카페/술집) + 모드별 상황 태그(다중 선택) 매칭
- ✅ 파비콘 + 공유(OG) 미리보기 이미지
- ✅ 상태 처리: 위치거부/에러 구분 · 결과없음(반경 확대 제안)
- ✅ **공공데이터 실연동** (소상공인 상권정보 API — 서버에서 키 은닉, 반경 내 음식점 실조회)
- ✅ **길찾기 in-app 감싸기**: 앱 내부 상세 시트(지도 미리보기·방향·거리·주소복사·내비앱 선택)
- ✅ **지도 미리보기**: 정적 지도(네이버 Static Map, 서버 프록시) + 탭하면 인터랙티브 지도(핀줌)
- ⏳ Vercel 배포 (진행 중)
